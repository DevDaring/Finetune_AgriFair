Independent recomputation of AgriFair fresh validation comparisons
================================================================

You are recomputing census shares from the published tables. You have not been given the
existing answer key, any model output, or the original study's labels, and you should not
look for them: the point of this check is that it is independent.

For each row:
  1. Open the parent table named in `parent_table` for the state in `state`.
  2. Read the two group values named in `group_1_to_read` and `group_2_to_read` for the
     metric in `metric`, within the stratum named in `source_cell`.
  3. Write each value as a percentage share of the stratum total in the `_recomputed`
     columns, and name the denominator you used.
  4. Compute the gap in percentage points.
  5. Mark the condition: gap below 5 points is `equal`; gap of 10 points or more is `diff`;
     anything between is `excluded` — write `excluded` and move on.
  6. Name the larger group, or write `Roughly equal` when the condition is `equal`.
  7. Record the page or table you read and your initials.

Leave a row blank and explain in `notes` if the source does not support the comparison.
Do not adjust a value to make it fit a band.
